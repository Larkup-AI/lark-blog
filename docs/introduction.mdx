Lark Blog Studio is an open-source blog CMS with an AI writing agent and
pluggable infrastructure. You own the data and choose every provider.

## What makes it different

- **Bring your own AI** — OpenAI, Anthropic, Google, xAI (Grok), DeepSeek,
  Mistral, Groq, OpenRouter, the Vercel AI Gateway, or any OpenAI-compatible
  endpoint (Ollama, LM Studio, vLLM). Pick the provider **and** model in Settings.
- **Any Postgres** — Neon, Supabase, RDS, Railway or local Docker.
- **Any object storage** — S3-compatible (AWS, R2, MinIO, B2, Spaces, Supabase,
  Tigris, Neon Object Storage), Vercel Blob, UploadThing or local disk.
- **Optional email** — Resend, SMTP, or none.
- **An editor agent that edits** — it writes section by section, rewrites your
  current selection, and can be stopped mid-generation.

## Open core

The core is MIT licensed. Enterprise features (SSO, SCIM, custom roles, audit
log, advanced scheduling) live under `ee/` and unlock with a license key.
