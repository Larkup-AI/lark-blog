---
title: Concepts
---

- **Workspace** — an isolated set of posts, settings and members. (Multi-tenant
  workspaces are on the roadmap; today a deployment is a single workspace.)
- **Provider** — a pluggable backend for AI, database, storage or email, chosen
  in Settings or via environment variables.
- **Studio API key** — used by the SDK to read your posts over the REST API.
- **Deployment mode** — `selfhost` (default) or `cloud` (multi-tenant + EE).
