---
title: Object storage
---

Set `STORAGE_PROVIDER` to one of `uploadthing` (default), `s3`, `vercel-blob`,
or `local`.

The **S3 adapter** is S3-compatible and covers AWS S3, Cloudflare R2, MinIO,
Backblaze B2, DigitalOcean Spaces, Supabase Storage, Tigris, and **Neon Object
Storage**. Install the AWS SDK and configure:

```bash
pnpm add @aws-sdk/client-s3 @aws-sdk/s3-request-presigner
```

```
S3_BUCKET=...  S3_ENDPOINT=...  S3_ACCESS_KEY_ID=...  S3_SECRET_ACCESS_KEY=...
S3_FORCE_PATH_STYLE=true   # MinIO and most S3-compatible stores
```

Uploads are presigned and go straight from the browser to the bucket.
